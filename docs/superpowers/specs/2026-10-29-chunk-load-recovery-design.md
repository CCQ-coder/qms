# 前端异步页面资源自动恢复设计

## 目标

当发布新版本后，已打开的浏览器标签仍引用旧的 Vite 异步页面资源，而该资源已从服务器移除时，系统自动刷新一次以加载最新入口文件，避免路由区域持续空白。

## 约束

- 只处理异步模块或 chunk 加载失败，不处理接口超时、接口 401 或普通运行时异常。
- 同一路由在同一浏览器会话中最多自动刷新一次，避免服务器持续异常时形成刷新死循环。
- 页面成功进入后清除该路由的恢复标记，使后续版本发布仍可自动恢复。
- 不改变现有鉴权、路由和 Service Worker 行为。

## 方案

新增独立的 chunk 加载恢复模块，由 Vue Router 的全局错误钩子调用。模块识别浏览器和打包工具常见的动态导入失败错误，使用 `sessionStorage` 记录当前路由已尝试恢复，然后执行整页刷新。路由成功完成后，由 `afterEach` 清除对应标记。

如果存储不可用，系统不会自动刷新，以免无法记录防循环标记；未识别的错误继续输出到控制台，供正常排查。

## 验证

- 单元测试覆盖错误识别、首次刷新、重复失败不刷新、成功后可再次恢复、普通错误不触发刷新。
- 执行 TypeScript 检查和生产构建。
