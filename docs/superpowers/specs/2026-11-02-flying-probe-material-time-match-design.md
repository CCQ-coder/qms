# 飞针料号与生产指令匹配设计

## 意图

让共赢飞针机上报的短料号（如 `42777`）关联厂内编号 `02PT42777A01` 的正确生产指令，并自动生成 FQC 增量检验。规则由租户在 QMS 系统参数中配置。

## 已确认规则

- 新增独立的飞针料号提取正则，使用唯一捕获组从生产指令的厂内编号提取中间数字；共赢配置为 `^02PT([0-9]{5})A[0-9]{2}$`。设备料号与捕获的数字全量相等，保留前导零。
- 按飞针来源文件的**开始时间**与生产指令的**下达日期**比较：只考虑不晚于文件开始日期的工单，选择下达日期最近的一单；同一天并列、缺日期或无候选时继续待匹配，不自动猜测。
- 同一来源文件的累计计数继续绑定首次选定的工单，不因后续设备检测时间跨月而改变归属。
- 未配置提取规则的租户保留现有厂内编号精确匹配。
- 原“料号规则”仍仅校验新建产品资料格式；不复用它的参数键。

## 方案

采用租户专用提取规则，并在投影时按业务下达日期消歧。复用产品资料格式校验会改变现有参数语义；在代码里固定 `02PT` 格式则无法由系统参数管理。新增规则保存时校验正则恰有一个捕获组，投影时校验捕获结果为数字。候选通过包含设备料号的数据库查询缩小范围，再由 Java 正则验证。

共赢租户缺少 `FLYING_PROBE_ELECTRICAL_V1` 模板：迁移补齐现有租户，租户创建流程补齐未来租户。旧文件首次保留快照继续只建立基线，后续新增板数才生成 FQC；不回填已无法确认的历史增量。

## 验证与边界

- `WTD-1/42777.txt` 开始于 2026-08-26，候选下达日期为 4/24、7/29、8/14、10/21，应选 8/14 的 `26080450`；11/2 的后续快照仍归该单。
- 测试保留前导零、无候选、晚于文件开始日期、同日并列、已绑定文件、无规则租户与无效正则；模板迁移须可在现有数据上运行。
- 上线前以只读查询估算待重试记录，备份数据库和应用；上线后核对投影原因、工单号及实际 FQC 数量。
