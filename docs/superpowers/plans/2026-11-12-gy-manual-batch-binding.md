# 共赢飞针手动批量绑定实施计划

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan task by task.

**Goal:** 在现有“未匹配”列表勾选同料号飞针文件，选择一条生产指令后手动批量绑定；修复弹窗单选框。

**Architecture:** 沿用待匹配文件分页列表和单条 `bindManually` 服务，新增一个批量手动绑定 HTTP 入口。页面仅提交当前页选中的文件 ID 和用户选择的工单，返回绑定、跳过、失败数量。移除上次增加的“生产指令为空”入口与自动批量匹配。

**Tech Stack:** Vue 3、Element Plus、Spring Boot、JUnit。

**Spec:** 用户 2026-11-12 对线上截图的更正：批量按钮放在“未匹配”视图；勾选记录后由弹窗手动选工单；单选框必须可见可用。
