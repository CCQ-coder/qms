## 状态口径

| 状态 | 含义 |
| --- | --- |
| 已实现 | 表中限定范围内的页面、接口或处理逻辑已存在；不代表所有边界场景、性能及现场验收均通过。 |
| 部分完成 | 已有基础代码，但缺少用户入口、关键关联、完整流程，或存在已识别的问题。 |
| 待联调 | 有实现，仍依赖客户设备、外部服务、运行平台或配置完成验证。 |
| 未完成 | 当前源码中未找到相应完整实现，或现有功能不能满足该项要求。 |

系统仅保留 QMS 账号密码登录；模块编号保留历史序号，移除项不计入后续交付。

本表不使用估算百分比。后续应以每行的范围和验收条件更新状态。文末保留源码依据，现有 README 和架构方案中的能力描述不直接等同于完成结果。

## 更新方法

每次迭代更新对应编号的状态，并附“变更日期、验证场景、结果、证据位置”。标记已验收时，至少记录使用的组织/角色、输入样例、预期结果和实际结果；凭据、令牌和个人敏感数据不写入进度表。未安排的工作保持待办，不填写推测的完成日期。
