# 共赢报废导入与匹配实施计划

**Branch:** `gy`。**Input:** 用户提供的《共赢报废单明细.xlsx》及四张标注截图。

## 任务

1. [x] 飞针五位数字提取和匹配：先写失败测试，保持数字料号模糊匹配及时间选择规则，再修改服务。
2. [x] 关闭设备不良品自动下推；单据与明细页加入截图筛选、单窗明细，保留现有手工新建和审核。
3. [x] 导入迁移、解析与匹配：测试十列表头、Excel 日期、最近且不晚于表格日期、同日并列、缺失字段、重复导入；保存原始值和未关联行。
4. [x] 异步任务、权限和 API：上传后立即返回任务 ID，后台处理及进度可查询；角色配置控制显示并在 API 校验；失败行可查看。
5. [x] 前端导入入口、进度、手工关联和明细七项查询；用附件作为本地验证样本，不对生产环境上传。
6. [x] 设备检测记录当前筛选结果多选批量绑定、更正、取消及跨界面同步；移除重复查询按钮。
7. [ ] 后端与前端全量测试、构建、检查迁移与部署风险；部署至共赢服务器并执行只读线上验证，记录备份和版本。
