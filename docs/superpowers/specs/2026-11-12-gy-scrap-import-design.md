# 共赢报废明细导入及匹配调整

## 目标

共赢用户上传现有十列表格后立即获得任务编号，后台逐行导入报废明细。用厂内型号在生产指令厂内编号中模糊匹配；五位数字须为独立数字段。仅考虑 `input_date <= 表格时间`，选择最近的唯一输入日期；无候选、日期缺失或最近日期并列时保留未关联明细供手工关联。保留 Excel 原始层数、面积、原因、责任部门、工站、备注，不覆盖业务已有数据。重复上传同一文件不重复生成单据。

停止设备不良数自动生成报废处置单，保留已有单据。报废单列表提供导入入口、任务进度、筛选和单窗明细；明细表提供七项筛选。导入权限由现有角色菜单配置控制并在后端校验。设备检测记录支持当前已加载结果多选绑定、更正、取消并反映到关联数据。飞针自动匹配从设备料号只提取连续五位数字，仍按原时间规则选择工单。

## 方案

- 复用已有 Apache POI 和不良品处置单/明细模型。增加导入任务及原始字段、导入行唯一键；后台定时领取任务。这样服务器重启后能继续处理，导入结果可查。直接在上传请求中处理会阻塞，纯内存异步任务在重启时会丢失进度。
- 报废单导入生成独立的 `EXCEL` 来源单据，未匹配行允许工单为空，只有手工关联后才进入工单关联数据。保留既有手工单据和已审核单据，不清理任何历史记录。
- 权限作为“报废单导入”功能项加入现有角色可见菜单设置；默认仅管理员可配置，拥有该项权限的角色才能调用上传接口和看到按钮。
- 用户多选只作用于当前已加载、当前筛选结果，服务端逐条校验租户及可改状态；已审核或状态变化的记录跳过并回报数量。

## 风险和边界

- Excel 仅支持附件展示的十列及现有导出格式（首行标题、次行表头），最大 10 MB。空行忽略，非法行反馈行号，不静默改写。
- 同一文件重传幂等，失败后重传可继续处理；原始文件保留在现有附件存储中供重试和审计。不自动发布、审核或撤销单据。
