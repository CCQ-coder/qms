# 共赢页面切换空白排查与发布

- 目标：`gy`，共赢 1Panel 服务器 `106.227.69.144`，前端 `/data/1panel/www/sites/qms/index/dist`。未改后端或数据库。
- 根因证据：站点原来对不存在的 `/assets/*.js` 返回 `200 text/html` 和 684 字节首页。访问日志中有 40 次这种响应，涉及旧版路由脚本；页面模块加载失败发生在发起数据请求之前。原路由兜底只向控制台写错，第二次失败没有可见提示。

- 调整：静态资源缺失返回 404；首页和 Service Worker 每次重新校验，带内容哈希的资源长期缓存；Service Worker 对已缓存脚本优先读取且不缓存 HTML 冒充的脚本；路由加载失败给出刷新提示。

- 验证：OpenResty 配置检查通过；HTTPS 域名的新旧脚本均返回 `200 application/javascript`，不存在的脚本返回 404，首页与 `sw.js` 返回 `Cache-Control: no-cache`，API 健康检查返回 200，登录页打开且浏览器无错误日志。登录后的具体业务页面需由现有账号继续观察。
